Pre entrega Proyecto Backend Node JS de Talento Tech, Ministerio de Educación de la Ciudad de Buenos Aires, Argentina


El proyecto implementa las operaciones de un CRUD para probar los endpoints consumiendo datos desde la API de Fakestoreapi
Operaciones básicas:

Get — getProduct consultar productos
Delete — deleteProduct limina productos
Post — createProduct crea productos

Tecnologías utilizadas

* Node.js
* JavaScript
* Fakestore


## 📋 Funcionalidades

La API permite:

* Crear nuevos registros.
* Obtener todos los registros.
* Eliminar un registro.
